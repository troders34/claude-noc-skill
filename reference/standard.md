# Specified standards

- Single-answer: exactly one option is unambiguously correct.
- Multiple-answer: 2-3 options are correct, and the question does not need to state how many to select
- Distractors reflect real mistakes technicians make: confusing similar protocols, wrong OSI layer, wrong command or flag, misreading output.
- Options have similar length and detail. The correct answer is not systematically the longest, and correct letters are spread across A-D.
- No "all of the above" or "none of the above".
- Difficulty matches the level definitions in difficulty-levels.md.
- Explanations say why the key is correct and why each wrong option is wrong.
- Use only commands and syntax you are confident about, and state the OS, tool, and version when it matters.
- Certification outlines guide topic coverage only. Never reproduce real exam questions.
